# CSCurricularAnalytics
This repository is for a capstone course for a master's degree in data science. I sought to analyze how curricular structure of computer science programs influences student graduation and attrition in computer science.

curriculum_graph_test.R is used for obtaining curricular graphs from institution degree plans.

cohort_processing.Rmd is used for creating models from curricular analytics metrics from an institution's degree plans over multiple cohorts to predict graduation and retention.

grad_simulation_comparison.R is used for comparing if the simulated graduation rate was significantly different across institutions.

grade_file_processing_by_school.Rmd is used for creating specialized passage rate files based on how courses are mapped from one institution to another.

grades_process.R was test file used to lessen the historical passage through data for the simulation purposes.

graph_processing was used for exploratory data analysis when comparing institutions with one another with regards to their curricular complexity.

Curricular Modeling and Visualization is a Julia Juypter Notebook where we simulated the pass through throughout multiple institution's CS curricula.
